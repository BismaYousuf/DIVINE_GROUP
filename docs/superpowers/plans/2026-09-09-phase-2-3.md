# Divine Group — Phase 2 + 3 Implementation Plan

> Continues `docs/superpowers/plans/2026-09-09-divine-group-website.md`.
> Spec: `docs/superpowers/specs/2026-09-09-divine-group-website-design.md` §2 (Phase 2, Phase 3).
> Page structure references: `docs/reliance_clone/*.md`. All infrastructure (tokens, motion
> system, primitives, layout, `/api/*`, Resend) exists from Phase 1 and is reused.

**Goal:** Design + animate the five remaining routes in the Phase 1 visual language, build the
full VIN + document-upload quote form, and stand up the hero scroll-frame-sequence
infrastructure (frames supplied later).

**Global constraints:** unchanged from Phase 1 — TS strict, Tailwind v4, server components by
default, `motion-safe:` gating for pins, `prefers-reduced-motion` renders static, animate only
transform/opacity/clip-path, 1.5 MB/file upload cap + ~4 MB total guard, all copy marked
`CLIENT TO CONFIRM`, `npx tsc --noEmit` + `npm run lint` + `npm run test` clean before each commit.

### Task P-9: Phase 3 — hero scroll frame sequence

**Files:** create `components/home/hero-frame-sequence.tsx`, `lib/hero-frames.ts`,
`public/media/hero-frames/README.md`; edit `components/home/hero-media.tsx`.

- `lib/hero-frames.ts`: `HERO_FRAME_COUNT` (default `0`), `heroFramePath(i)` →
  `/media/hero-frames/frame_${String(i).padStart(4,"0")}.webp`, `HERO_FRAME_PIN_VH = 180`.
- `HeroFrameSequence` (client): `<canvas>` fixed in the hero; preload all frames (`new Image()`),
  show the static hero image until decoded; a `{ f: 0 }` object tweened `0 → count-1` on a
  `ScrollTrigger` `{ pin, scrub, end: "+=" + count*something }`; `onUpdate` → `drawImage` with
  cover-fit math + `devicePixelRatio`. Cleans up on unmount.
- `HeroMedia`: `if (HERO_FRAME_COUNT > 0 && desktop && !reduced) render <HeroFrameSequence/>`
  else the existing static `<Image>` (unchanged). So with no frames committed, behaviour is
  identical to Phase 1.
- `README.md`: how to export/optimise ~90–120 WebP frames ≤ 1600px wide, name them, set
  `HERO_FRAME_COUNT`, mobile stays on the poster.
- [ ] With `HERO_FRAME_COUNT = 0`: hero unchanged, build passes. Temporarily set to a small
  count with duplicated placeholder frames to smoke-test the scrub, then revert to 0. Commit.
